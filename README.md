# Spotify Music Analytics Dashboard

## Overview
An interactive Power BI dashboard designed to explore Spotify music data, analyze song popularity, and visualize trends across artists, songs, and album types.

## Key Features
- Total Songs and Artists KPIs
- Average Song Duration
- Average Popularity Score
- Song Distribution by Artist
- Most Popular Songs
- Explicit Songs by Album Type
- Monthly Popularity Trends
- Monthly Song Distribution

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- Dashboard UI Design
